# Public holidays for the periods of the bundled event logs

Public holidays in Poland (2010), the United States (2004, 2008, 2009)
and Great Britain (2026).

## Usage

``` r
public_holidays
```

## Format

A data frame with 75 rows: `country` (ISO code), `date`, `name`,
`local_name`.

## Source

Nager.Date public holiday API, <https://nagerholidays.com/>, accessed
2026-10-17. Holiday dates and names are facts.
