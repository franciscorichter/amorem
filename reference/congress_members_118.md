# Members of the 118th US Congress

Sponsors and cosponsors appearing in
[congress_bills_118](https://franciscorichter.github.io/amorem/reference/congress_bills_118.md).

## Usage

``` r
congress_members_118
```

## Format

A data frame with 553 rows: `bioguide_id`, `name` (as printed in the
bill status), `party`, `state`.
